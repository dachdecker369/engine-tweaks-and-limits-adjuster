# Roadmap

What I plan for TweaksV next, before it is planned in [PLAN.md](PLAN.md) and specified in [SPECIFICATIONS.md](SPECIFICATIONS.md). This file is new with 2.0.0; nothing stood here before 2.1.0, because TweaksV did what I wanted it to do. Two versions are planned now, 2.2.0 and 2.2.1, both from a player's report: with NaturalVision Enhanced installed, TweaksV crashed the game. I reproduced it with NVE in my own game folder and narrowed it, part by part, to three of TweaksV's eight - DirectStorage, RageOpenV and StraightToStoryMode, each alone enough - and the game folder told the rest: TweaksV's diagnostic log, the ASI loader's log, Windows' application log for the crashes the game did not dump and the game's crash dump for the one it did. Nothing of NVE's code was read.

## 2.2.0 - the DirectStorage part frees the files instead of refusing them

**What is wrong.** `UNLOCK_FILES` refuses every file the game asks DirectStorage for in the game folder that is not an `.rpf` or `.cache` file, on the premise that the game reads only archives there (PATTERNS.md, "When Game Updates", item 5). A mods loader that serves loose files breaks the premise: NVE's bundled loader, `onigiri.asi`, keeps its files under `onigiri\` - 91 loose files, xml, dat, ymt, ytd and meta, next to 14 archives - and hands them to the game through DirectStorage's `OpenFile`. TweaksV refused `onigiri\common\data\gameconfig.xml`, and 22 milliseconds later the game died in its own fatal trap (exception 0x80000003 inside `GTA5_Enhanced.exe`). Any loader that serves loose files would do the same. This is TweaksV's bug.

**The redesign.** Nothing is refused any more. TweaksV hooks `NtCreateFile` in `ntdll.dll` at start-up - today it does so with `DIAGNOSTIC_MODE` only, to log the opens - and widens the sharing of the opens that lock the game folder's files: an open of a file inside the game folder that is not `.rpf` or `.cache`, for reading only, that already shares reading, gets write and delete sharing too. The file opens, the game or the loader reads it, and other programs can still write, rename and delete it while the game runs, which is what `UNLOCK_FILES` is for. Archives stay locked as before; write opens, exclusive opens, directories and files outside the game folder are never touched. The game's DirectStorage factory is no longer needed for the job: the factory and `OpenFile` hooks stay as diagnostic aids, a factory request that never comes becomes a diagnostic line (NOTES.md, T-DIAG), and the one thing that can go wrong, a hook that cannot be made, is a problem of the start-up summary. The limit, which README.md will state: a program that opens a file for writing while sharing nothing gets a sharing violation while the game holds the file open; one that shares reading, as editors, the C runtime's file functions and a rename do, is not affected. `UNLOCK_FILES` keeps its name and its meaning, so `TweaksV.ini` keeps layout 2.

## 2.2.1 - two parts switch themselves off next to NVE's loader

**What is wrong.** `onigiri.asi` does two of TweaksV's jobs: it is a mods loader, and it skips the splash and legal screens by its own INI (`SkipSplash` and `SkipLegal` on, `SkipIntro` off). It loads before TweaksV but patches after it, at the game's first request for the time, and uses what it finds unchecked: with the cache check, the five RPF encryption calls or the two screens' bytes changed by TweaksV, it faults with an access violation. Windows names `onigiri.asi` 1.0.1.0 as the faulting module in every such crash, at its offset 0x1ea45 after RageOpenV's changes and 0x1f2be after StraightToStoryMode's. That is onigiri's bug, and TweaksV cannot fix it: it cannot make another mod check its results, it can only leave those sites alone while that mod is installed.

**The change.** `onigiri.asi` becomes a plugin the conflict check knows - not an old one TweaksV replaces, but one that does the job and stays. While it is installed, the RageOpenV and StraightToStoryMode parts are switched off for the session, said in the start-up summary in words of their own, with the INI switches that stop the message. NVE's users then get the splash and legal skips from onigiri, their mods through its folder, and the rest of TweaksV as before.
